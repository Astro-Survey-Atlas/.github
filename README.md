# Astro-Survey-Atlas Organization Profile (.github)

**English** | [简体中文](./README_ZH.md)

This repository contains the organization-wide configuration, templates, and profile for the [Astro-Survey-Atlas](https://github.com/Astro-Survey-Atlas) GitHub organization.

## 📁 Repository Structure

*   `profile/`
    *   `README.md`: The main organization profile page displayed on the Astro-Survey-Atlas home page.
*   `.github/` *(optional, for future templates)*
    *   `ISSUE_TEMPLATE/`: Organization-wide issue templates.
    *   `PULL_REQUEST_TEMPLATE.md`: Organization-wide PR templates.

## 🚀 How to Edit

1. To update the organization landing page, edit the [profile/README.md](./profile/README.md) file.
2. Changes merged into the `main` branch will automatically reflect on the [Astro-Survey-Atlas GitHub Organization Page](https://github.com/Astro-Survey-Atlas).
