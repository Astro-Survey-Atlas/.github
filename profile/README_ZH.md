# Astro-Survey-Atlas 🌌🔭

[English](./README.md) | **简体中文**

欢迎来到 **Astro-Survey-Atlas** 开源组织！我们是一个致力于构建下一代、高性能、且极具视觉冲击力的开源工具集体，专注于探索天文巡天数据、深空星表（Catalogs）以及交互式星图（Celestial Atlases）。

我们的使命是消除复杂天文观测数据与直观、研究级可视化之间的壁垒——让天文学家、教育工作者和天文爱好者都能更轻松地探索宇宙。

---

## 🎯 我们的愿景

在海量天文数据的时代（随着维拉·鲁宾天文台、詹姆斯·韦布空间望远镜 JWST、欧几里得卫星 Euclid 以及盖亚卫星 Gaia 的运行，每天都在产生 PB 级的数据），查找、可视化并进行巡天覆盖范围（Footprints）的交叉匹配变得日益复杂。我们正在构建一个模块化的开源工具生态系统，用于：

*   **🌌 星空可视化：** 基于高性能 Canvas 和 WebGL 渲染天球及多波段星图。
*   **🗺️ 巡天覆盖范围叠层（Footprint Overlay）：** 交互式映射并对比各大望远镜和巡天计划（如 SDSS、DESI、HST、Pan-STARRS 等）的观测覆盖区域。
*   **⚡ 简化数据访问：** 提供轻量、快速的 API 和界面，用于检索恒星/星系表和天空瓦片数据。
*   **🎓 科学普及与教育：** 打造交互式的网页端工具，让任何人只需通过浏览器即可畅游宇宙。

## 🚀 核心生态与规划项目

以下是我们正在开发（或计划构建）的项目一览：

| 项目名称 | 描述说明 | 技术栈 | 当前状态 |
| :--- | :--- | :--- | :--- |
| **`astro-atlas-core`** | 高性能的天球坐标转换与投影核心库。 | Rust / WebAssembly | 🏗️ 研发中 |
| **`sky-footprint-mapper`** | 用于在网页上叠层、对比不同望远镜观测覆盖范围的交互式工具。 | React / TypeScript / Deck.gl | 🗺️ 活跃开发 |
| **`catalog-crossmatch`** | 针对海量天体源的快速空间索引与星表交叉匹配。 | Python / Rust | ⚡ 规划中 |
| **`cosmos-explorer-ui`** | 精美且兼具交互性的宇宙星空探索网页前端界面。 | Next.js / TailwindCSS / Three.js | 🎨 设计阶段 |

我们坚信，星空属于每一个人，开源科学也是如此！无论你是专业的天体物理学者、软件工程师、前端/UI设计师，还是对宇宙充满好奇的业余天文爱好者，这里都有属于你的位置。

1.  **💻 代码与设计：** 参与核心仓库开发，优化空间查询性能，或为星图设计更优美的视觉呈现。
