# Astro-Survey-Atlas 组织个人主页 (.github)

[English](./README.md) | **简体中文**

该仓库托管了 [Astro-Survey-Atlas](https://github.com/Astro-Survey-Atlas) GitHub 组织的全局配置、模板以及组织主页文件。

## 📁 目录结构

*   `profile/`
    *   `README.md`: 组织的英文版主页文件。
    *   `README_ZH.md`: 组织的中文版主页文件。
*   `.github/` *(未来可用于存放组织级模板)*
    *   `ISSUE_TEMPLATE/`: 全局 Issue 模板。
    *   `PULL_REQUEST_TEMPLATE.md`: 全局 PR 模板。

## 🚀 如何进行修改

1. 若要更新组织的 GitHub 主页展示，请编辑 [profile/README.md](./profile/README.md) 或 [profile/README_ZH.md](./profile/README_ZH.md)。
2. 更改合并到 `main` 分支后，将自动实时呈现于 [Astro-Survey-Atlas GitHub 组织主页](https://github.com/Astro-Survey-Atlas)。
